## 🎯 ¿Qué es Flutter?

**Flutter** es un framework de código abierto desarrollado por Google que permite crear aplicaciones multiplataforma utilizando una única base de código.

Permite desarrollar aplicaciones para Android, iOS, web y escritorio mediante el lenguaje de programación **Dart**.

Su arquitectura se basa en widgets, componentes que permiten construir y organizar las interfaces gráficas de las aplicaciones.

### ¿Qué es Dart?

**Dart** es un lenguaje de programación desarrollado por Google, utilizado principalmente junto a Flutter.

Durante las primeras actividades del módulo se trabajan los fundamentos del lenguaje, incluyendo tipos de datos, estructuras de control, funciones, colecciones y programación orientada a objetos.

## 📚 Conceptos trabajados

### Dart — Fundamentos ✅

- Declaración de variables y tipos de datos.
- Constantes mediante `const` y `final`.
- Sound Null Safety y variables nullable.
- Operadores aritméticos, lógicos y de comparación.
- Condicionales y estructuras de control.
- Bucles `for` y `while`.
- Colecciones `List`, `Map` y `Set`.
- Records y enumeraciones.
- Funciones y parámetros (opcionales, por defecto y nullable).
- Funciones recursivas.
- Creación e importación de librerías propias.
- Entrada y salida por consola mediante `dart:io`.
- Generación de números aleatorios con `dart:math`.
- Gestión de excepciones mediante `try-catch-finally`.
- Manipulación de cadenas: `toUpperCase()`, `toLowerCase()`, `trim()` y cadenas multilínea.
- Conversión de tipos mediante `parse()` y `toString()`, y formato de decimales.
- Inversión de palabras y caracteres mediante `reversed` y `join()`, y comprobación de palíndromos.
- Búsqueda de subcadenas mediante `contains()`, `indexOf()` y `lastIndexOf()`.
- Conversión de colecciones (`split()`, `map()`, `toSet()`, `Map.from()`) y JSON (`dart:convert`).

### Dart — Próximos contenidos ⬜

- Expresiones regulares y validación de datos.
- Menús interactivos para gestionar colecciones.
- Manejo de URI y fechas con `intl`.
- Funciones anónimas, funciones flecha y funciones de orden superior.
- Programación orientada a objetos.
- Herencia, abstracción y composición.
- Pruebas unitarias.

### Flutter — Próximos contenidos ⬜

- **Widgets:** componentes fundamentales de las interfaces.
- **StatelessWidget:** widgets sin estado mutable propio.
- **StatefulWidget:** widgets capaces de gestionar cambios de estado.
- **Árbol de widgets:** organización jerárquica de la interfaz.
- **Layouts:** distribución mediante `Row`, `Column`, `Container` y `Stack`.
- **Navegación:** gestión de pantallas y rutas.
- **Gestión del estado:** actualización de datos e interfaces.
- **Material Design:** componentes y principios de diseño visual.

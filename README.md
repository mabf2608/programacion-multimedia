# Fundamentos y Teoría de Flutter

> Documentación, apuntes y material teórico sobre el desarrollo de aplicaciones multiplataforma con Flutter.

## ¿Qué es Flutter?

**Flutter** es un framework de desarrollo multiplataforma creado por Google que permite desarrollar aplicaciones para Android, iOS, web y escritorio utilizando un único código base. Está basado en el lenguaje de programación **Dart** y utiliza un sistema de widgets para construir las interfaces de usuario.

## Herramientas y conceptos trabajados

### Entorno y Desarrollo

* **Flutter SDK:** Instalación y configuración del entorno de desarrollo de Flutter.
* **Dart:** Lenguaje utilizado para desarrollar aplicaciones y lógica dentro de Flutter.
* **Visual Studio Code:** Entorno de desarrollo utilizado para trabajar con proyectos Flutter.
* **Control de versiones:** Organización y seguimiento del material mediante Git y GitHub.

### Arquitectura y Componentes

* **Widgets:** Elementos fundamentales utilizados para construir las interfaces de usuario.
* **StatelessWidget:** Componentes cuya interfaz no mantiene un estado mutable.
* **StatefulWidget:** Componentes capaces de gestionar y actualizar su estado.
* **Árbol de widgets:** Estructura jerárquica utilizada por Flutter para representar las interfaces.

### Interfaz y Aplicaciones

* **Layouts:** Organización de elementos mediante widgets como `Row`, `Column`, `Container` y `Stack`.
* **Navegación:** Gestión de las diferentes pantallas y rutas de una aplicación.
* **Gestión del estado:** Conceptos y mecanismos para controlar y actualizar los datos de la interfaz.
* **Material Design:** Uso de componentes y principios de diseño para crear interfaces consistentes.
